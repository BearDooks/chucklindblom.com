# SEO Configuration File for Sabatucci Construction Website
# Use this when preparing the site for production layout.

## 1. Global SEO Tags & Recommendations
- Ensure all images have `alt` text defined (already implemented on projects.html).
- Add an XML Sitemap when the site goes live.
- Create a `robots.txt` file to instruct search engines.
- Add `<link rel="canonical" href="https://www.sabatucciconstruction.com/current_page">` to each page.
- Consider adding JSON-LD structured data for a Local Business (see snippet below).
